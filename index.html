Politique de confidentialité de Baladog

Dernière mise à jour : 3 octobre 2026

Baladog est une application destinée à aider les propriétaires de chiens à anticiper les croisements avec d'autres chiens pendant leurs promenades.

Données utilisées

Baladog peut traiter les informations suivantes :

  • la position géographique de l'utilisateur pendant une balade ;
  • les informations relatives aux chiens enregistrés dans l'application ;
  • les signalements créés par l'utilisateur ;
  • un identifiant technique anonyme nécessaire au fonctionnement de l'application.

Géolocalisation

Lorsque l'utilisateur démarre une balade et autorise l'accès à sa position, Baladog utilise la géolocalisation pour assurer les fonctionnalités de localisation et de proximité.

Selon les autorisations accordées sur l'appareil, la localisation peut également être utilisée en arrière-plan afin de maintenir le suivi d'une balade active.

Utilisation des données

Les données sont utilisées pour permettre notamment :

  • les fonctionnalités de proximité entre utilisateurs ;
  • les alertes de proximité ;
  • l'affichage des signalements ;
  • le fonctionnement et la sécurité du service.

Stockage et services techniques

Baladog utilise Firebase, un service fourni par Google, notamment pour l'authentification anonyme et le stockage des données nécessaires au fonctionnement de l'application.

Partage des données

Baladog ne vend pas les données personnelles des utilisateurs. Certaines informations nécessaires aux fonctionnalités de proximité peuvent être accessibles aux autres utilisateurs de Baladog.

Conservation des données

Les données sont conservées pendant la durée nécessaire au fonctionnement des fonctionnalités concernées. Certaines données temporaires, notamment les positions de balade et les signalements, peuvent expirer ou être supprimées automatiquement.

Autorisations

L'utilisateur peut modifier ou retirer les autorisations de localisation depuis les paramètres de son appareil.

Suppression des données

L'utilisateur peut demander la suppression des données associées à son utilisation de Baladog en contactant l'éditeur de l'application.

Enfants

Baladog n'est pas spécifiquement destinée aux enfants.

Modifications

Cette politique peut être mise à jour afin de refléter les évolutions de Baladog ou les exigences réglementaires applicables.
