Suppression des données Baladog

Dernière mise à jour : 3 octobre 2026

Baladog ne nécessite pas la création d'un compte utilisateur avec une adresse e-mail ou un mot de passe. L'application utilise un identifiant technique anonyme pour son fonctionnement.

Demander la suppression de vos données

Pour demander la suppression de tout ou partie des données associées à votre utilisation de Baladog :

  1. Envoyez un e-mail à baladog.contactfr@gmail.com.
  2. Indiquez dans l'objet : Demande de suppression des données Baladog.
  3. Précisez les données que vous souhaitez faire supprimer ainsi que toute information utile permettant d'identifier les données concernées.

Données pouvant être supprimées

Selon votre utilisation de Baladog, la demande peut concerner notamment :

  • les informations relatives aux chiens enregistrés ;
  • les données liées aux balades ;
  • les positions géographiques enregistrées ;
  • les signalements créés ;
  • les données associées à l'identifiant technique anonyme.

Conservation des données

Les données concernées par une demande de suppression seront supprimées lorsqu'elles peuvent être identifiées et qu'aucune obligation légale ou de sécurité n'impose leur conservation.

Certaines données temporaires de Baladog, notamment certaines positions et certains signalements, peuvent également expirer ou être supprimées automatiquement dans le cadre du fonctionnement normal de l'application.
